# 🎵 Music Player System

Player de música em **HTML, CSS e JavaScript** com lista de reprodução, controles de play/pausa, avançar/voltar e barra de progresso.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)

---

## ✨ Funcionalidades

- Controle de **play / pause**
- Navegação de faixas (**anterior / próxima**)
- Barra de progresso com tempo atual e duração total
- Playlist definida no arquivo `songs.js`
- Interface responsiva com ícones Boxicons

## 🚀 Como executar

```bash
# com Python
python -m http.server 8080
```

Acesse [http://localhost:8080](http://localhost:8080) e abra o `index.html`. As faixas de áudio estão na pasta `src/`.
